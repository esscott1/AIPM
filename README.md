# AIPM — AI Program Manager

One Claude Code session that runs a project team in each of my repos, so I stop switching between sessions.

- **PM session** in this repo takes my commands, dispatches work and approves pull requests.
- **Fleet MCP server** runs one persistent Claude Code project team per repo.
- **Project teams** own their branches and worktrees and spawn subagents for spikes, planning and research.
- **Reconcile** keeps AIPM in sync with work done directly in a repo, outside AIPM.

**Status:** Phase 0 — design documents. Next: Phase 1 scaffold.
